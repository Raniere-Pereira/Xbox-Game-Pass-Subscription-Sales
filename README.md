
# Xbox Game Pass Subscription Sales

Interactive Excel dashboard for analyzing Xbox Game Pass subscription sales and customer behavior.

## 📊 Project Overview

The project analyzes subscription data to answer business questions related to:

* Total subscription revenue
* Revenue by subscription type
* Auto-renewal behavior
* Subscription plans
* Additional services and season passes
* Coupons and discounts

## 📁 Workbook Structure

* **Bases** — Subscription and customer dataset
* **Cálculos** — Business questions, calculations and analysis
* **Dashboard** — Interactive sales dashboard
* **Assets** — Visual assets and dashboard design elements

## 🛠️ Tools

* Microsoft Excel
* Pivot Tables
* Data Analysis
* Dashboard & Data Visualization

## 🎯 Objective

Transform subscription data into actionable insights to support analysis of **sales, customer behavior and subscription performance**.
